A forecaster for how many GTA VI players earn each of the 55 PlayStation 5 trophies in week one. It models each trophy's earn rate as earners over players-tracked: a stale launch-night snapshot awaiting its first refresh is diluted (tracked population grows, new players earn at a fraction of the old rate), while a history with real movement is extrapolated in logit space against log time since release, blended with a separate earners-over-tracked extrapolation. Quantiles are logit-normal around the median. Deterministic, offline, standard library only.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
